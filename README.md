# CAD-PROFILE
Short tagline (for the GitHub "About" box): Parametric aerospace CAD models, UAV airframes, and clean watertight geometries prepared for CFD/FEA and rapid prototyping.
Parametric 3D CAD assemblies and surface-modeled components focused on aerospace and fluid systems—including airfoils, ducted enclosures, and variable-geometry mechanisms. Geometries are structured with clean topology for meshing/simulation workflows as well as tolerances tuned for FDM 3D printing.
